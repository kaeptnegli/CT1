# CT1 setup

See [Ennis (CT wiki)][ennis-start] for instructions on installing
Keil. \
The Keil projects are distributed as ZIP archives named `keil.zip`.
There is a root directory in the archive, so you can extract it
without extra steps.

In case you would rather avoid Keil, follow the instructions in
`./setup-gnu-toolchain.md`.
